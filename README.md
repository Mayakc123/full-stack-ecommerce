\# 🛍️ Full-Stack E-Commerce Application



A full-stack e-commerce web application built using React, Node.js, Express.js and MongoDB.



This project includes a customer-facing shopping application, backend REST APIs and a separate admin panel for managing products.



\---



\## 🚀 Features



\### 👤 User Features



\- User registration and login

\- Browse products

\- Browse products by category

\- Product details page

\- Product image display

\- Product size selection

\- Add products to cart

\- View and manage cart items

\- Product quantity management

\- Related products section

\- Responsive shopping interface



\### 🛒 Shopping Features



\- Men's products

\- Women's products

\- Kids' products

\- New collections

\- Popular products

\- Product pricing

\- Product categories

\- Shopping cart



\### 🔐 Authentication



\- User signup and login

\- Authentication using backend APIs

\- JWT-based authentication



\### 🛠️ Admin Panel



\- Separate admin application

\- Add new products

\- View product list

\- Manage products

\- Product image upload



\### 🗄️ Backend



\- REST API

\- Express.js server

\- MongoDB database

\- Mongoose for database interaction

\- JWT authentication

\- Product management APIs

\- Cart APIs

\- User authentication APIs
